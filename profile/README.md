# Orbix Lab

We build open-source software and custom digital solutions. Our main project is **[Artemis](https://github.com/orbixtechteam/Artemis)**, an open-source AI agent that lives on your computer: you pick the model, you keep the data, and you press approve.

## What we do

- **Open source**: Artemis and other tools we share with the community.
- **Software development**: desktop, web and AI-powered applications built to fit your needs.
- **Web design**: clear, fast websites that represent your business well.
